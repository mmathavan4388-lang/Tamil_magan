# Product Images

Drop real product photos here using the exact filenames referenced in
`src/data/products.js` (each product's `image` field), e.g.:

```
digital-bomb.jpg
flower-pot-big.jpg
7cm-color-sparklers.jpg
```

Any product whose image file is missing automatically falls back to a
clean placeholder in the UI (see `src/components/ProductImage.jsx`), so
the site works fully before real photos are added.
